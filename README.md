# 💰 Personal Finance & Expense Dashboard v1.0

A modern, lightweight, and responsive personal finance manager designed to help you track expenses, manage multi-currency accounts, and monitor investments seamlessly—all within a clean single-page interface.

---

## 🚀 Key Features

* **Transaction Management:** Easily log, categorize, and delete income and expense entries in real-time.
* **Multi-Currency Support:** Switch effortlessly between different currencies to manage global finances.
* **Investment & Transfer Hubs:** Dedicated modules for tracking asset allocations, high-yield options, and micro-investments.
* **Data Persistence:** All records and states are securely saved locally using browser `localStorage`.
* **Interactive UI:** Smooth dropdowns, dynamic modals, and interactive financial charts.
* **Progressive Web App (PWA):** Fully optimized to be installed as a standalone desktop application directly from your browser.

---

## 🛠️ Built With

* **HTML5** – Semantic structure and layout
* **CSS3** – Responsive styling, modern flexbox/grid architecture, and UI polish
* **Vanilla JavaScript (ES6+)** – Core application logic, DOM manipulation, and state management
